   PGlite avec données de test. La sélection de fichiers et les prises de vue sont
   simulées : aucun essai matériel de l’appareil photo Android n’est revendiqué.
   Aucun message réel publié, aucun changement effectué dans Supabase en production.
   Les originaux restent stockés selon le fonctionnement existant ; cette version
   réduit les images affichées dans le fil sans refondre tout le chargement initial.
   La réussite des tests locaux ne constitue pas un déploiement : installer le ZIP
   puis attendre la réussite de GitHub Pages pour mettre à jour les utilisateurs.
